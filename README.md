# homelabPersonal
Self-hosted Linux infrastructure for containerized AI services, Kubernetes orchestration, and monitoring.

# Overview
The goal of this project is to build, deploy, and monitor containerized applications on a dedicated Linux homelab server, using a Dell laptop as the host machine. It is built around Ubuntu Linux, Docker, Kubernetes, and self-hosted AI inference.

# Planned Technology
- Operating System: Ubuntu Linux
- Containerization: Docker
- Orchestration: Kubernetes (K3s)
- Backend: Python, FastAPI
- Monitoring: Prometheus, Grafana
- AI Inference: llama.cpp
- Automation: GitHub Actions

# Planned Features
- Remote Linux administration using SSH
- Containerized REST API
- Kubernetes application deployment
- System and application monitoring
- Self-hosted LLM inference
- Automated testing and container builds

# Architecture
MacBook (Development) → Wi-Fi Network → Dell (Ubuntu Linux) → Kubernetes → Containerized Services
